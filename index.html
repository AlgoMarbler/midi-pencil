With Draw, drag an empty space to set the note length. Existing notes can still be moved. In automation, Draw paints values and Line creates a straight ramp. Velocity edits affect selected notes when there is a selection, otherwise all notes in the checked tracks. Pedal and tempo changes use normal MIDI events. Beat inputs use quarter-note beats, starting at 1. Check multiple tracks to edit them together, and choose Write to for new notes. Drag the dividers to resize panels. Alt + scroll zooms pitches over the piano roll and resizes the automation panel over its lane. Use View or the corner fullscreen buttons to expand a panel; Escape restores the split view.

Place yamaha.sf2 beside index.html to load it automatically on first playback or keyboard audition. Serve the folder over localhost or HTTPS; browsers usually block automatic access to neighboring files when opening HTML directly. In Options → Soundfont, you can also select any .sf2 or .sf3 file manually. MIDI instruments follows each channel’s program and bank changes; choosing a preset uses it for all channels. You can also drop a soundfont onto the editor or return to the built-in synth.

The chosen soundfont and preview instrument stay separate from the MIDI file. Exports retain the original instrument and other MIDI events. Standard MIDI format 0 and 1 with musical tick timing are supported.
